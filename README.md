# React Native Mobile App

Aplicação mobile de portfólio desenvolvida com **React Native, Expo e TypeScript**.

O projeto foi criado para demonstrar competências em desenvolvimento mobile, composição de interfaces, organização de componentes visuais e criação de experiências responsivas para dispositivos móveis.

## Tecnologias

- React Native
- Expo
- TypeScript
- StyleSheet API

## Funcionalidades

- Dashboard mobile responsivo
- Cards de métricas
- Indicador visual de progresso
- Lista de atividades recentes
- Estrutura visual organizada e reutilizável
- Interface adaptada a diferentes tamanhos de ecrã

## Objetivo

Este projeto integra o meu portfólio técnico e demonstra conhecimento prático de React Native e TypeScript aplicado a interfaces mobile.

## Executar localmente

```bash
npm install
npm start
```

Depois, utilize Expo Go ou um emulador Android/iOS para abrir a aplicação.
